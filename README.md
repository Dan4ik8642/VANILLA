# Vanilla Coffee — минималистичный лендинг

Откройте `index.html` в браузере. Сборщик не нужен.

## Что внутри
- минималистичная визуальная система в нежно-розовых/ванильных тонах;
- параллакс на главном экране;
- CSS 3D-чашка и 3D tilt-карточки;
- адаптив для телефона, планшета и десктопа;
- актуальные факты из Яндекс Карт и официального Telegram Vanilla Coffee;
- контактная форма;
- телефон, Telegram, адреса сети;
- встроенная Яндекс Карта + кнопка на исходную геоссылку.

## По логотипу
Официальный Telegram-канал и Яндекс Карты подтверждают бренд Vanilla Coffee, однако публичный источник не дал скачать исходник логотипа в рабочую среду. Поэтому в проекте используется аккуратный текстовый бренд-марк `assets/vanilla-wordmark.svg`. Если передадите официальный PNG/SVG, его можно заменить без изменения дизайна.

## Форма
В `script.js` есть константа:
`const WEBHOOK_URL = '';`

Туда можно подключить Telegram-бота, n8n, Make, Bitrix24, amoCRM или собственный backend.
